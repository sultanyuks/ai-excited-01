A neon spiral galaxy vortex swirls into a blazing heart at its core — deep violet arms ignite through magenta and hot orange to gold around a white-hot heart wrapped in thin gold pulse rings. Every pixel is computed procedurally in pure Python (standard library only): polar spiral math for the arms, the classic implicit heart curve for the core, and 250 seeded stars, with the PNG encoded by hand using zlib and struct.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
